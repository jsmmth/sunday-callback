# sunday-callback

Nothing to see here. This is a small helper site for my own personal assistant, Sunday, which runs on my Mac. It isn't a product or a public service, so you can safely ignore it.

It contains two static pages:

- `index.html`: after I approve read-only access at my bank, the bank sends me back here, and this page passes that approval straight on to the app on my Mac. It stores nothing, uses no cookies and loads nothing from anywhere else.
- `privacy.html`: the privacy policy that Google and the open-banking provider ask for.

There are no secrets in this repo. The code on its own can't access anything without keys that never leave my computer.
